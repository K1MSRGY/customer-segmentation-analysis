# Customer Segmentation Analysis

## Описание проекта

Excel-проект по сегментации клиентов и анализу активности филиалов.

## Инструменты

- Microsoft Excel
- Формулы Excel
- Customer Segmentation
- Data Analysis

## Задачи проекта

- Анализ клиентской активности
- Сегментация клиентов по истории взаимодействия
- Анализ активности филиалов
- Агрегация данных по регионам
- Работа со справочниками и датами
- Подготовка аналитических показателей

## Сегменты клиентов

Клиенты были разделены на группы:

- Новый
- Действующий
- Спящий
- Ушедший

## Использованные инструменты

- IF
- COUNTIF
- COUNTIFS
- SUMIF
- SUMIFS
- VLOOKUP / XLOOKUP
- Ranking
- Data Aggregation

## Результат

Проект позволяет оценивать активность клиентской базы, определять статус клиента и анализировать показатели филиалов и регионов.
